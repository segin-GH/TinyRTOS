# Setting a bit versus using a numeric literal

The learner initially proposed ANDing xPSR with a binary mask to set its T bit. When asked to consider an initial value of zero, they independently changed their proposal to ORing the value, demonstrating recognition that setting requires OR; the teacher supplied the bit-24 mask (1u << 24) and corrected the proposed binary mask's bit-23 position. They then correctly explained that the numeric literal 24 is not the same as having bit 24 high; independent mask construction and hexadecimal conversion remain to be checked.
