Observe the hardware frame

Goal: inspect a real exception frame in QEMU/GDB before constructing a task's initial frame.

SVC is a synchronous exception requested by the svc instruction. We will use svc #0 as a controlled trigger. See the primary Arm guide, SVC instruction and exception model.

Your first change

In rtos/src/main.c, add one GCC inline-assembly statement to execute svc #0 once, before the while loop. Show your attempted line in chat; we will review it before rebuilding. For the syntax, read the short GCC Basic Asm reference.

Current startup has SVC routed to Default_Handler, which loops forever. We will stop there in the debugger to inspect the saved frame. Current main uses MSP; task use of PSP has only been discussed, not configured. This first observation therefore uses MSP.

Feedback loop

After reviewing the trigger, we will predict the frame, rebuild with debug information, break at Default_Handler, and compare saved PC and xPSR with the source and disassembly. We will establish each debugger command together; a source change alone does not complete this observation.

Ask your teacher followup questions about inline assembly, the exception, or debugger state whenever a step is unclear.
