# Tracing a memory copy through registers

With concrete addresses and guided questions, the learner correctly predicted the copied value, identified the destination address after r1 changed, and identified _sidata as the source-address symbol loaded into r0. This demonstrates an initial ability to distinguish a copied value from a memory address in the ldr/str pair; independent application and broader assembly fluency remain unverified.

Next, connect the startup symbols to their linker-script definitions. Do not assume the learner yet understands load versus runtime addresses or data/BSS initialization.
