The printk path

message → string writer → UART byte output → QEMU → terminal
String writer
Passes each byte to the output function in order. The terminating zero marks the end.
Polling UART output
Reads transmit status repeatedly while the buffer is full. Sends one byte once the peripheral has room.
First caller
main(), after UART initialization and before the first task launch. One caller lets you verify the output path independently of scheduling.
Future formatter
Turns values such as a semaphore count into printable characters. The UART still receives one byte at a time.
