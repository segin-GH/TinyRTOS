The CPU saves part of the context

Goal: predict the stack space used when an ordinary interrupt pauses your task. Your RTOS can build on this hardware operation.

On ordinary Cortex-M3 exception entry, before the handler executes, hardware saves eight 32-bit words onto the interrupted code’s current stack: r0, r1, r2, r3, r12, lr, pc, xPSR. The saved PC provides the resume address; xPSR includes the condition flags you just investigated. Source: Arm guide, §2.3.7, Exception entry.

This hardware stack frame is only part of the context. It does not include r4–r11. We will investigate the software’s responsibility after this exercise.

Your prediction

Assume SP begins at 0x20001000, with enough valid stack memory below it. The stack grows toward lower addresses. For this example there is no extra alignment word, no nesting, and no tail-chaining.
