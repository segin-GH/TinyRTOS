Choose the bit, then the operation

For our Cortex-M3 target's 32-bit unsigned int, bit positions start at 0. Use positions 0 through 31 with these expressions.

mask = 1u << position;
value |= mask;          // Set the selected bit; preserve other bits.
selected = value & mask; // Keep only the selected bit for inspection.
initial_value = mask;    // Start with only the selected bit set.

A position and a mask are different: 24 is a numeric value, while 1u << 24 selects bit position 24.

Initial task execution state

The saved xPSR for our initial task needs T at bit 24 set. A fresh value with that bit alone is 1u << 24. This initializes a saved frame field in RAM; it does not write the live status register.
