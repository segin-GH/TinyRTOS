Which stack receives the save?

Goal: distinguish the interrupted task's saved frame from the handler's own stack operations before writing RTOS context-saving code.

Cortex-M3 has a Main Stack Pointer (MSP) and a Process Stack Pointer (PSP). Thread mode can use either; Handler mode uses MSP. Our planned setup gives tasks PSP and handlers MSP. These are CPU stack pointers, not one hardware register per task; each task record retains its saved stack address. See Arm guide, §2.1.2–2.1.3.

When an interrupt pauses A while A uses PSP, hardware saves A's eight-word frame onto A's task stack. The handler then executes using MSP. The frame stays where it was saved; it is not moved onto the handler stack. See §2.3.7, Exception entry.
