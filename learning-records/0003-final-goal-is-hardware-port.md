# Final goal is a hardware port

The user clarified that the final goal is to port the RTOS to an ST microcontroller, provisionally interpreted as STM32. [MISSION.md](../MISSION.md) and [LEARNING-PLAN.md](../LEARNING-PLAN.md) now include hardware bring-up and port validation. The exact device is unknown, so do not assume the final core is Cortex-M3 or that MPS2 startup and peripheral configuration can be reused unchanged.
