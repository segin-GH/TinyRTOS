TINYRTOS REFERENCE

First binary semaphore

  • Token capacity: one. Initially empty.
  • Take: consume an available token, otherwise block waiting for this object.
  • Give: release the waiter if present, otherwise store one token.
  • One give releases one take; do not both release a waiter and retain its token.
  • Repeated gives without a take coalesce into one token.
  • Checking the token and registering the waiter must be atomic relative to give.
  • First version: one waiter, task callers, no timeout. Tick processing must not wake event waiters.
