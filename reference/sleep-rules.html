TINYRTOS REFERENCE

Sleep rules

  • saved_sp stays at task-record offset zero.
  • READY means eligible; SLEEPING means excluded.
  • Positive sleep publishes count/state atomically and requests PendSV.
  • Zero sleep requests a yield only.
  • Each tick decrements positive sleeping counts; zero makes a task ready.
  • Round robin chooses ready application tasks; idle runs only if none are ready.
  • Idle has its own stack and saved context; it never sleeps.
  • Save PRIMASK, mask interrupts, publish and pend, restore PRIMASK.
  • C calls from an assembly handler require preserving exception-return LR and eight-byte call-stack alignment.
  • Tick delays count boundaries; ready does not mean immediately running.
