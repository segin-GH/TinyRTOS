Trace startup with evidence

For each initialization loop in rtos/src/startup.S, identify:

  1. The register holding the destination address.
  2. The exclusive end address: stop before writing there.
  3. The value written and, if copied, its source.
  4. The number of bytes advanced after each store.

Use linker symbols to connect the instructions to section boundaries. The GNU linker manual explains load versus runtime addresses and shows corresponding copy and clear loops.

Prediction → build current source → stop at a known instruction → inspect registers and memory → compare with prediction.
