Prepare the initial execution state

Goal: express one required bit in a new task's saved xPSR. This connects bit manipulation to starting your own RTOS tasks.

You identified task_b's entry address for the initial frame's PC slot. The xPSR slot also matters: it includes the Thumb-state T bit at bit position 24. Cortex-M3 executes instructions only in Thumb state, so the initial frame must have T = 1. Exception return restores this state from the stacked xPSR. Primary source: Arm guide, §2.1.3, Thumb state and Table 2-6.

One bit-manipulation step

Bit positions are numbered from 0 at the least-significant bit. For this exercise, start with all bits zero and create a value with only bit 24 set.
